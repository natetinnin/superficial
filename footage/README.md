# footage/

Source material for edits: clips (`.mp4`) and stills (`.png`/`.jpg`). **Not in
git** (repo is public). Keep this layout on each machine:

```
footage/
  ref01/            shots cut out of references/ref01 (already graded, so use --grade none)
    clips/          20 shots, 0.25-1.9 s each
    labels/         9 clothing-label stills for the ending burst
    unused/         shots kept out on purpose
  mine/             the user's own photos and clips (put new material here)
```
